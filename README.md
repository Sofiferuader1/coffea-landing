# Coffea - Landing Page

## Descripción del proyecto

Coffea es una landing page para una cafetería ficticia, desarrollada como parte del Trabajo Práctico N.º 4 de la materia Diseño UX-UI de la Licenciatura en Sistemas de Información (2026).

El objetivo del proyecto es reproducir un diseño de Figma utilizando HTML5 y CSS3, respetando su estructura, colores, tipografías y componentes visuales.

## Diseño de referencia

Coffea - Free Responsive Coffee Shop Website Template.

Diseño disponible en Figma Community.

## Tecnologías utilizadas

- HTML5 semántico.
- CSS3.
- Flexbox y CSS Grid.
- Variables CSS (Custom Properties).
- Media Queries.
- Scroll Snap para carruseles.
- Google Fonts.

El proyecto no utiliza JavaScript ni frameworks.

## Secciones desarrolladas

1. Header y navegación.
2. Hero con imagen principal.
3. Categorías de productos.
4. Our Special Coffee.
5. Our Special Dessert.
6. Promoción Coffee Beans.
7. Testimonios de clientes.
8. Newsletter.
9. Footer con redes sociales.

## Funcionalidades

- Navegación mediante enlaces internos.
- Tarjetas de productos con imágenes y precios.
- Corazones de favoritos mediante CSS.
- Carruseles con desplazamiento horizontal.
- Efectos hover en botones y tarjetas.
- Formulario de newsletter con validación HTML5.

## Diseño responsive

Se implementaron estilos responsive mediante Media Queries para adaptar el contenido a distintos tamaños de pantalla.

La versión móvil se encuentra parcialmente implementada.

Problemas conocidos:
- Desbordamiento horizontal en determinadas condiciones.
- Dificultades para visualizar completamente el Footer en la vista móvil.
- Menú hamburguesa pendiente de implementación.

## Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir index.html con Live Server.
4. Visualizar la página en el navegador.

No requiere instalación de dependencias.
